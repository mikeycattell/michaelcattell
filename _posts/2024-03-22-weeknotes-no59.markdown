Let me be the first person to let you know.. when doing barcodes - get ready to be wowed by how they are done.<br>

I've trained multiple designers on how to use the HTML prototype kit, and given additional training to the new Design System Manager and it's been really fun doing it all, even writing up the documentation for it!
